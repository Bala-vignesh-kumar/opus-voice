Piper voice swap for Fineract demo
18:42 · notes/2026-08-30/
Summary

Went over swapping opus voice's Piper output for the en-IN medium model before Thursday's Fineract client walkthrough — the current default voice reads loan terms with the wrong emphasis on lakh/crore figures. Tried the medium model locally against a handful of Nakshatra Residence payment-plan sentences and it held up; latency stayed under the 300ms budget on the demo laptop. Landed on shipping the new voice behind the existing model-select flag rather than swapping the default outright, so the change can be rolled back mid-demo without a restart.

Decisions
  • Ship en-IN medium Piper voice behind the model-select flag, default stays unchanged
  • Demo script narrates two Fineract loan scenarios, not the full Nakshatra flow
  • Whisper transcription stays on-device for the demo — no cloud fallback
Action items
